# نظام إدارة معرض حور — نسخة Windows المستقلة

تم تجهيز المشروع ليعمل كتطبيق Windows عادي داخل نافذته الخاصة، باستخدام Electron لعرض واجهة React وإدارة خادم Express محلياً. لا يحتاج المستخدم إلى فتح المتصفح أو تشغيل Node.js يدوياً بعد التثبيت.

## ما تم تضمينه

تحتوي نسخة سطح المكتب على جميع الشاشات والوظائف الموجودة في المشروع، بما في ذلك تسجيل الدخول، نقطة البيع، المنتجات والمخزون، التوريدات، التقسيط، العملاء والموردون، المصروفات، التقارير، الموظفون، النسخ الاحتياطي وإعادة الضبط.

تُحفظ قاعدة البيانات وملفات النسخ الاحتياطية في مجلد بيانات المستخدم على Windows بدلاً من مجلد التثبيت المحمي، لذلك تبقى البيانات قابلة للكتابة ولا تحتاج الصلاحيات الإدارية أثناء التشغيل. عند أول تشغيل، تُنسخ قاعدة البيانات الأولية تلقائياً إذا لم توجد قاعدة بيانات سابقة.

## بناء نسخة التطوير

```bash
pnpm install
pnpm build
pnpm desktop
```

الأمر الأخير يفتح البرنامج داخل نافذة Electron محلية. الخادم يستمع على `127.0.0.1` فقط، ولا يتم نشره على الشبكة.

## إنشاء ملف التثبيت EXE

```bash
pnpm dist:win
```

ينتج المثبّت في:

```text
dist/HawrGallery-Setup-2.4.0.exe
```

المثبت من نوع NSIS، ويتيح اختيار مجلد التثبيت، وينشئ اختصاراً في قائمة Start وعلى سطح المكتب، ويشغّل البرنامج بعد انتهاء التثبيت. إزالة البرنامج لا تحذف بيانات المستخدم تلقائياً.

## التثبيت على جهاز Windows

انسخ ملف `HawrGallery-Setup-2.4.0.exe` إلى جهاز Windows، ثم شغّله واتبع خطوات المثبّت. بعد ذلك افتح **نظام إدارة معرض حور** من الاختصار. لا تحتاج إلى Chrome أو أي متصفح أو تثبيت Node.js.

إذا كان هناك إصدار سابق، يُفضّل أخذ نسخة احتياطية من شاشة النسخ الاحتياطي داخل البرنامج قبل تحديثه. لا تُحذف قاعدة البيانات أثناء تحديث ملفات التطبيق.

## ملاحظات البناء

النسخة المستهدفة حالياً هي Windows x64. تم اختبار استجابة الخادم المجمّع ومسار قاعدة البيانات محلياً، كما تم إنشاء ملفات التطبيق ومثبت NSIS. يجب اختبار التثبيت النهائي على جهاز Windows فعلي قبل التوزيع الواسع.
